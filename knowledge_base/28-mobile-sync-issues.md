# Fixing mobile sync problems

If the mobile app shows out-of-date data, first pull down to refresh. If that does not help, confirm you are online and signed into the correct workspace. Force a full resync from Settings > Sync > Resync in the app. Changes made offline sync when you reconnect; if an offline change conflicts with a newer server change, the server version wins and your change is kept as a comment on the task so nothing is lost.
