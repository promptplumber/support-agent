# Creating and managing projects

Create a project from the Projects tab with New Project. Give it a name, an optional color, and choose which members can access it. Projects hold tasks, sections, and a timeline. On the free Starter plan you can have 2 active projects; archived projects do not count. Archive a project from its settings menu to keep its data without it counting toward limits. Only Owners and Admins can delete a project, which is permanent.
