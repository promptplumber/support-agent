# Importing data from other tools

Import tasks from a CSV file from Settings > Import. Your CSV needs at least a task title column; optional columns are assignee email, due date (YYYY-MM-DD), status, and project. Rows with an unknown assignee email are imported unassigned. We also have guided importers for Trello and Asana that map boards and lists to projects and sections. Imports over 5,000 rows run in the background and email you when done.
