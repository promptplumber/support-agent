# Two-factor authentication (2FA)

Turn on 2FA from Settings > Security > Two-factor authentication. Nimbus supports authenticator apps (TOTP) and, on Business, hardware security keys. When enabled, you enter a 6-digit code from your app after your password. Save the backup codes shown during setup; each can be used once if you lose your device. Admins can require 2FA for the whole workspace. If you are locked out, an Admin can reset your 2FA.
