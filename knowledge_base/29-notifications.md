# Notification settings

Control notifications from Settings > Notifications. Choose per-event whether you get email, in-app, and push notifications, for events like assigned to a task, mentioned in a comment, and task due soon. Due-soon reminders go out 24 hours before the due date by default; you can change this. Set Do Not Disturb hours to pause push notifications. Workspace-wide notification defaults are set by Admins but each person can override them.
