# Nimbus is slow or not loading

If Nimbus is slow or a page will not load, first check status.nimbus.example for a known incident. If all is green, hard refresh the page, then try an incognito window to rule out a browser extension. A very large project with thousands of tasks loads faster if you filter or archive completed tasks. The web app supports the latest two versions of Chrome, Edge, Firefox, and Safari; older browsers may be slow.
